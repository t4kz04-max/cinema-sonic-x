# CINEMA SONIC X 使い方ガイド

音声・動画ファイルを、ブラウザの中だけで立体音響・重低音に加工して書き出すアプリです。
**ファイルはお使いの PC のブラウザの中でだけ処理し、サーバーや外部のサービスへは送りません。**

> 注意: 開発中の確認はすべて合成した信号と、試験用に作った動画での測定です。**実際の楽曲・ヘッドホンでの試聴による評価はまだ行っていません。**
> 試聴の確認は [ヘッドホン試聴チェックリスト](LISTENING_CHECKLIST.md) で行ってください。

## 必要な環境

| | 最低限 | 推奨 |
| --- | --- | --- |
| OS / 端末 | Windows・macOS・Linux の PC | Windows 10 / 11 の PC |
| ブラウザ | Chrome または Edge（AudioWorklet・WebCodecs に対応した最近の版） | Chrome / Edge の最新版（開発・試験は Chrome 155 / Edge 155） |
| メモリ | PC のメモリ 8 GB | 16 GB 以上。**Windows の空きメモリ 2 GB 以上**（長い素材・動画は 3 GB 以上）|
| 試聴 | イヤホン・スピーカー | ヘッドホン（CINEMA 3D・360° MOTION・IMMERSIVE X はヘッドホン向け）|
| 接続 | `https://` または `localhost` で開く（AudioWorklet が使える。`file://` などでは簡易の処理になり、その旨を画面に表示）| |

- Firefox・Safari は「動けばよい」扱いで、確認していません
- スマートフォン・タブレットでは**動画の書き出しは使えません**（メモリと処理時間の制約。画面に理由を表示）。音声の書き出し・試聴はできますが、実際の端末では確認していません

## 対応形式

| 種類 | 形式 | 上限 |
| --- | --- | --- |
| 音声 | WAV（PCM 16 / 24 / 32-bit・float）、MP3 | 300 MB |
| 音声（ブラウザが対応していれば） | FLAC、Ogg（Vorbis・Opus）、M4A（AAC）、WebM（音声のみ）。読み込めない場合はエラーを表示 | 300 MB |
| 動画 | MP4・MOV（H.264 / AAC など）、WebM・MKV（VP9 / Opus など）。中身でコンテナ・コーデックを判定。音声トラックが必要 | 1 GB |
| 書き出し（音声） | WAV 16-bit（標準、TPDF ディザ）/ 24-bit（高音質）、元のサンプルレート・ステレオ | 30 分・メモリの見積もりの上限まで |
| 書き出し（動画） | 入力と同じコンテナ。映像は再エンコードせずにコピー、音声は AAC（MP4 / MOV）/ Opus（WebM / MKV）| 動画 1 GB |

- 実際のカメラ・スマートフォン・編集ソフトで作った動画、MP3 以外の圧縮音声の実ファイルは未確認です

## SIMPLE MODE（かんたん。初めての方向け）

画面の上の「SIMPLE」。5 つの手順を上から順に進めます。

1. **ファイルを選ぶ**: 音声・動画ファイルをドロップするか、クリックして選びます。下にファイル名・種類・再生時間・サンプルレート・チャンネル数（動画は解像度）が出ます
2. **プリセットを選ぶ**: 4 枚のカードから 1 つ。すぐに試聴の音に反映されます
   - **CINEMA 3D**: 映画館のスクリーンの前で聴くような響き。セリフ・歌声は真ん中のまま
   - **LIVE ARENA**: 大きなライブ会場の響き。スピーカーでも可
   - **360° MOTION**: 周りの音がゆっくり動く
   - **IMMERSIVE X**: 4 つの中でいちばん立体的
   - ヘッドホン向けの 3 つは、音の方向（前・後ろ・まわり）の感じ方に個人差があります。頭の中や後ろに聞こえる場合もあります
3. **プレビュー**: 再生（Space キーでも可）。**ORIGINAL（元の音）⇄ PROCESSED（加工した音）** を切り替えて聴き比べます（B キーでも可）。加工した音は元の音と同じくらいの音量にそろえています
4. **加工を開始**: 音声は「〇〇 で WAV を作る」。動画は「立体音響の動画を作る」か「音声だけ取り出す（WAV）」を選んでから押します。PREPARING → RENDERING → ENCODING →（動画は MUXING）→ COMPLETE と進み、途中でキャンセルできます。加工に使うメモリの目安が表示され、多いときは警告が出ます
5. **ダウンロード**: 完成したファイルを EXPORTED（完成ファイル）⇄ ORIGINAL（元のファイル）で聴き比べ、「ダウンロード」で保存します

失敗したときは、原因と再試行の方法が表示されます（「もう一度書き出す」）。メモリが足りないときは、他のアプリ・ブラウザのタブを閉じてからもう一度試してください。

## STUDIO MODE（詳細設定）

画面の上の「STUDIO」（または URL の末尾に `#studio`）。上部のリンクで各セクションへ移動できます。

- **PRESET**: 4 つのプリセット。詳細設定を変えると CUSTOM になり、保存できます（このブラウザ内にだけ保存。音声・ファイル名は保存しません）
- **SPATIAL**: 空間モード（OFF / WIDE / CINEMA / HALL）、INTENSITY・ROOM SIZE・DEPTH・WET/DRY、ステレオの測定値
- **MOTION**: ON / OFF、CINEMATIC / ORBIT / SWEEP / PULSE、速度・深さ・CENTER LOCK
- **TAIL**: NATURAL / DISTANCE / RIPPLE、長さ・レベル、Dynamic Tail、LOOP の種類
- **BASS**: 重低音エンジンの ON / OFF、NORMAL / EXTREME、BASS BOOST・SUB BASS、出力補正
- **EXPORT / VIDEO**: WAV 16 / 24-bit、元の音声の WAV、動画（余韻: 映像の長さを保つ / 最後のフレームを延ばす）

SIMPLE と STUDIO を切り替えても、読み込んだファイル・設定・再生位置・音量・書き出しの設定・完成ファイルはそのままです。

## メモリの目安（測定値。3 分の素材、Chrome / Edge、ブラウザ全体）

| 使い方 | ブラウザ全体のメモリ |
| --- | --- |
| 起動しただけ | 約 0.6〜0.9 GB（ほとんどはブラウザ自体。アプリの分は 0.1 GB 未満）|
| 音楽の再生 | 約 0.85〜1.0 GB |
| WAV 書き出し | ピーク 約 1.2〜1.25 GB（終わると 約 1.0 GB）|
| 動画書き出し（640×360）| ピーク 約 1.2〜1.25 GB |

- 長い素材ほど増えます。書き出しの前に必要なメモリを見積もり、上限を超える場合は始めません
- 30 分の連続再生でメモリが増え続けないこと、書き出しを 5 回続けても積み上がらないことを確認しています（Chrome）

## 既知の制限

- 前後の定位（HRTF）は個人差があり、成立しない人がいます。HRTF を使うプリセットは高音（8〜10 kHz）が少し下がります
- 低音が多くピークの多い曲（EDM など）では、加工した音が元の音より 1.5〜3 LU ほど小さくなることがあります（ピークを −1 dBFS 以下に抑えるため）
- リミッターはサンプルピークで制御します（True Peak ではありません。サンプル間のピークは天井をわずかに超えることがあります）
- 書き出し中は再生できません（終わると再開できます）
- 試聴で聴く音と書き出した音は、周波数特性・音量・幅などの統計的な指標では一致しますが、Motion を使う設定ではサンプル単位では一致しない場合があります（聴いて分かる差ではない想定。未確認）
- Edge で、まれに HRTF の処理が止まる問題がありました（対策後の試験では 0 回。原因は未確定）。止まったときは監視が中止し、もう一度書き出せます。ブラウザのタブごと応答しなくなった場合は、ページを読み込み直してください
- 実際の楽曲・ヘッドホンでの試聴、実際の動画ファイル、スマートフォン・タブレットの実機での確認は未実施です（開発・自動の検証は完了し、実機での受け入れ確認を待っている段階です）
