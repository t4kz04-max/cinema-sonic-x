# CINEMA SONIC X ヘッドホン試聴チェックリスト（利用者が行う評価）

この表は、**実際の楽曲とヘッドホンで人が聴いて確かめる項目**です。開発中の確認はすべて合成した信号での測定（数値）で、
**試聴による評価はまだ行っていません**（Claude Code は音を聴けないため、試聴の結果は書けません）。結果は下の欄に記入してください。

## 準備

- ブラウザ: PC の Chrome または Edge（最新版）
- ヘッドホン: できれば密閉型・開放型の 2 種類。スピーカーでも LIVE ARENA だけは確認する
- 音量: アプリの音量は 40%（既定）から始め、PC 側の音量を小さめにしてから上げる
- 曲: 次の 4 種類を用意する（自分で権利を持つ音源、または手元の購入した音源）
  1. ボーカル中心のポップス 2. 低音の多い EDM / ヒップホップ 3. アコースティック・クラシック 4. 映画・ドラマの台詞を含む動画
- 各プリセットで、ORIGINAL（元の音）と PROCESSED（加工した音）を B キーで何度か切り替えて比べる

## 共通（4 プリセットすべて）

| # | 確認すること | 判定の目安 | 結果（○ / △ / ×・メモ） |
| --- | --- | --- | --- |
| 1 | ORIGINAL ⇄ PROCESSED の切替でクリック・プツッという音がしない | 再生中に 10 回切り替えて一度も聞こえない | |
| 2 | 切替で音量が大きく変わらない | 「大きい方が良く聞こえる」差がない（加工は原音の音量にそろえている） | |
| 3 | 歪み・音割れがない | サビ・キックの強い所で割れない | |
| 4 | 低音が膨らみすぎない・こもらない | 原音より低音が増えても、ボーカルが埋もれない | |
| 5 | 高音がきつくならない・こもらない | シンバル・サ行が刺さらない | |
| 6 | 曲の終わりの余韻が自然に消える | 途中で切れたり、不自然に伸びたりしない | |
| 7 | 長時間（10 分以上）聴いて疲れないか | 耳が痛くならない | |
| 8 | 書き出した WAV / 動画をダウンロードして別のプレイヤーで再生しても、アプリで聴いた音と同じ | 明らかな違いがない | |
| 9 | 完成ファイルの EXPORTED ⇄ ORIGINAL の切替で、クリック・大きな音量差がない | | |

- × や △ がついた項目は、プリセット名・曲の種類・ヘッドホンの機種と一緒に記録し、既定値の調整（docs/PHASES.md の Phase 09 以降）に使う
